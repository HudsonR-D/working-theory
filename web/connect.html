Demo Library Use Grok

Bring the Grok you already have.

No API keys. No developer console. You sign into Grok the ordinary way, then paste a Working Theory lesson card as the first message.

If you do not have Grok yet

  1. Open an X account if you need one.
  2. Open grok.com and sign in with that X account.
  3. If Grok asks to subscribe, that is your LLM plan. Working Theory does not charge separately.

Each time you want a lesson

  1. On the demo page, pick a scripted scene or write what you saw.
  2. Tap Copy lesson card for Grok.
  3. Paste that card as the first message. Do not add “just tell me they have X.”
  4. Read more than one name. If Grok gives a single verdict, remind it: names are vocabulary, not a diagnosis.
