- Product is education / translator, not therapy or relationship advice.
- Subject is agnostic (self / other / “someone I know”).
- Relationship is a chat filter, not IA.
- Condition names are allowed; person-level diagnosis is not. Names ≠ verdicts.
- Auth: no user-pasted API keys. Demo free. Live tutor requires the user’s LLM.
- Primary promoted provider: X / xAI.
- Failure modes to design against: sycophancy, diagnosis, hallucination, jury behavior.
- Door B is the destination (on-site tutor after official sign-in). Door A ships day one so it works while we wait on native/app approval. Unofficial ChatGPT session reuse is rejected.
